# Portfólio Exponha | Luciane de Paula

As oito imagens WebP na pasta `assets/` são capturas reais fornecidas pela usuária, em versões de capa e página completa.

## Publicação no GitHub

O arquivo `index.html` do repositório LuPS27/portfolio-exponha já foi atualizado para referenciar estas imagens.

Para exibi-las no site, envie os 8 arquivos WebP desta pasta para `assets/` no repositório GitHub, preservando os nomes. O repositório ainda não contém essas imagens até que sejam enviadas.

Após isso, publique pelo EasyPanel e configure portfolio.exponha.com na Hostinger.
